# Thẻ sinh viên HUST — Jetpack Compose

1. Tạo project mới trong Android Studio: **Empty Activity** (Jetpack Compose), Minimum SDK 24.
2. Thay nội dung `app/src/main/java/<package>/MainActivity.kt` bằng file `MainActivity.kt` ở đây
   (sửa dòng `package` cho trùng tên package của project).
3. Copy 3 ảnh trong `res/drawable/` (`avatar.jpg`, `logo_hust.png`, `qr_code.png`)
   vào `app/src/main/res/drawable/`.
4. Mở `MainActivity.kt`, chọn chế độ **Split/Design** để xem Preview `StudentCardPreview`.
5. Chụp toàn màn hình (Windows: `Win + Shift + S` hoặc `PrtSc`; macOS: `Cmd + Shift + 3`).
